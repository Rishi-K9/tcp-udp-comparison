# Deployment Configuration and Rollback Evidence

## Project Type

This project is a documentation-based comparison of TCP and UDP transport-layer protocols.

## Deployment Configuration

The project consists of Markdown documentation hosted in a public GitHub repository. No application server or executable application is required to view the report.

## Deployment Status

The documentation is available through the public GitHub repository.

## Rollback Procedure

Since this project does not deploy an application, rollback refers to reverting documentation changes in Git.

1. Open the repository on GitHub.
2. Navigate to the file or commit that needs to be reverted.
3. Review the changes before reverting them.
4. Use GitHub's revert functionality when available, or restore the previous file contents.
5. Verify that the repository contains the intended version.

## Evidence Status

No application deployment or rollback has been performed. Actual rollback evidence should be added only after a change has been reverted and the result has been verified.

# Deployment Configuration

## Project

TCP and UDP Comparison Report

## Hosting Platform

GitHub Pages

## Deployment Method

The project is published using GitHub Pages from the main branch and the repository root directory.

## Source Configuration

- Branch: `main`
- Folder: `/ (root)`
- Source files: `README.md` and `report.md`

## Verification

The published website was opened successfully after enabling GitHub Pages.

## Rollback Strategy

Rollback will be performed by reverting a documented change through GitHub commit history. The published site will be checked again after the rollback to verify the result.
